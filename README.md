# Abdul Basit – Portfolio
React + Vite. Content lives in `src/data.js`.

    npm install
    npm run dev      # local
    npm run build    # production build in dist/

Deploy: `npx vercel` (framework auto-detected: Vite, output `dist`).
Profile photo: drop `public/media/profile.jpg` and swap the `.avatar` block in `src/App.jsx`.
